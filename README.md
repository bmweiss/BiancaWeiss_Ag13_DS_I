# 🎬 Meu Portal de Entretenimento Digital

Portal web estático que reúne conteúdos de entretenimento em três categorias: **Filmes e Séries**, **Música e Podcasts** e **Games e Tecnologia**.

## 📋 Sobre o Projeto

Página HTML (`portal.html`) com cards de imagem + descrição para cada conteúdo. Projeto focado em praticar HTML5 e CSS3 (estrutura semântica, classes e layout com tabelas).

## 🖥️ Funcionalidades

- Layout organizado por categorias:
  - 🎥 **Filmes e Séries** — Crepúsculo e Stranger Things
  - 🎵 **Música e Podcasts** — Mariah Carey e Apple Podcasts
  - 🎮 **Games e Tecnologia** — Resident Evil Requiem e DeepSeek
- Cards com imagem + descrição
- Classes CSS reutilizáveis (`principal`, `filmes`, `musicas`, `jogos`)
- Meta tags de SEO básico e responsividade (`viewport`)
